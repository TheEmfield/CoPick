# CoPick Algorithm

Чистая реализация алгоритма подбора фильмов для группы. Не зависит от Spring, БД и внешних API — принимает готовые данные, возвращает результат.

## Быстрый старт

```
CoPickAlgorithm algo = new CoPickAlgorithm();
AlgorithmConfig config = new AlgorithmConfig(); // параметры по умолчанию

// 1. Профиль группы (чтобы узнать коэффициенты для запроса к API)
GroupProfile profile = algo.calculateGroupProfile(participants);

// 2. Подборка фильмов (Шаги 0–4). useMmr = true включает диверсификацию
List<ScoredMovie> result = algo.generateRecommendations(
    participants, 
    contextGenreIds, 
    candidates, 
    config, 
    true
);
```

## Кто готовит данные

Алгоритм **ничего не знает** о БД, API и внешних сервисах. Он работает только с DTO.

**Основной бэкенд сам отвечает за:**

- загрузку предпочтений участников из БД и создание `ParticipantPreference`;
- вызов Go-коннектора, получение фильмов и маппинг строковых жанров API во внутренние `Integer genreId` для создания `MovieCandidate`;
- создание `AlgorithmConfig` (конструктор по умолчанию, там все параметры уже вписаны);
- передачу списка `contextGenreIds` (настроение «сегодня»).

---

## Методы алгоритма

### `calculateGroupProfile(List<ParticipantPreference> participants)`

Агрегирует предпочтения всех участников встречи в единый профиль группы. Считает средние веса жанров, выявляет жанры с абсолютным вето и нормализует положительные предпочтения в коэффициенты влияния для формирования запроса к внешнему API.

| <br>      | Тип                           | Описание                                                         |
| --------- | ----------------------------- | ---------------------------------------------------------------- |
| **Вход**  | `List<ParticipantPreference>` | Список предпочтений участников сессии                            |
| **Выход** | `GroupProfile`                | Агрегированный профиль: средние веса, вето, коэффициенты влияния |

### `generateRecommendations(...)`

Запускает полный конвейер: жёсткое вето → личные оценки → групповая оценка → контекст и качество → опциональная диверсификация MMR. Возвращает финальную подборку фильмов.

| <br>      | Тип                           | Описание                                        |
| --------- | ----------------------------- |-------------------------------------------------|
| **Вход**  | `List<ParticipantPreference>` | Предпочтения участников                         |
| <br>      | `List<Integer>`               | Контекстные жанры «сегодня» (может быть пустым) |
| <br>      | `List<MovieCandidate>`        | Фильмы-кандидаты от API                         |
| <br>      | `AlgorithmConfig`             | Параметры алгоритма                             |
| <br>      | `boolean`                     | Флаг использования MMR (по умолчанию true)      |
| **Выход** | `List<ScoredMovie>`           | Отсортированная подборка (по убыванию Final)    |

## Входные структуры данных

### ParticipantPreference

Предпочтения одного участника встречи.

```
public record ParticipantPreference(
    int profileId,                    // ID профиля из БД
    Map<Integer, Double> genreWeights // genre_id -> weight (от -1.0 до 1.0)
)
```

**Важно:** `-1.0` = абсолютное вето. Если жанр отсутствует в мапе, вес считается равным 0.0.

### MovieCandidate

Фильм-кандидат, полученный от Go-коннектора.

```
public record MovieCandidate(
    int movieId,           // ID фильма
    String title,          // Название (для логирования/отладки)
    Set<Integer> genreIds, // Внутренние genre_id из БД
    double rating,         // Рейтинг 0-10
    int voteCount          // Количество голосов
)
```

**Важно:** Go-коннектор возвращает строковые жанры (`"action"`, `"comedy"`). Оркестратор **обязан** сопоставить их с `genre_id` из таблицы `genres` перед передачей в алгоритм. Алгоритм принимает только числовые ID.

### AlgorithmConfig

Параметры конвейера.

```
public record AlgorithmConfig(
    double lambda, // штраф за нелюбимый жанр
    double alpha,  // баланс среднее / наименее довольные
    double beta,   // бонус контекста «сегодня»
    double rho,    // поправка за качество (рейтинг API)
    double mu,     // баланс релевантность / разнообразие (MMR)
    double kappa   // вес "смягчённого вето" на контекстный жанр
    int M,         // размер пула кандидатов для MMR
    int K          // размер итоговой подборки
)
```

В проде лучше использовать конструктор по умолчанию. С другими параметрами будем запускать только для калибровки алгоритма.

### contextGenreIds

Настроение «сегодня» — список `Integer` жанров. Может быть пустым.

## Выходные структуры данных

### GroupProfile

Результат `calculateGroupProfile`.

```
public record GroupProfile(
    Map<Integer, Double> averageWeights,             // Средние веса жанров по группе
    Set<Integer> vetoedGenreIds,                     // Жанры с вето
    int participantCount,                            // Количество участников
    Map<Integer, Double> genreInfluenceCoefficients  // Нормализованные веса (сумма = 1.0)
)
```

**Как использовать:**

- `vetoedGenreIds` — исключи эти жанры из запроса к API.
- `genreInfluenceCoefficients` — число от 0 до 1, которое нужно умножить на желаемое общее количество фильмов от API. Например, если `genreInfluenceCoefficients = [{1, 0.2}, {2, 0.7}, {3, 0.1}]` и нужно 100 фильмов, то коннектору запрашивается: жанр 1 — 20 шт., жанр 2 — 70 шт., жанр 3 — 10 шт.

### ScoredMovie

Фильм с итоговой оценкой.

```
public record ScoredMovie(
    int movieId,        // ID фильма
    double finalScore,  // Итоговая оценка Final
    Set<Integer> genreIds, // Жанры фильма
    double qualityScore // Q (используется для tie-break при сортировке)
)
```

`generateRecommendations` возвращает `List<ScoredMovie>`:

- Отсортирован по убыванию `finalScore`.
- Размер: `min(K, количество кандидатов после вето)`.
- Пустой список, если после вето не осталось фильмов или у участников группы противоположные вкусы.

## Параметры по умолчанию AlgorithmConfig

| Параметр | Значение | Описание                                   |
| -------- | -------- | ------------------------------------------ |
| lambda   | 0.5      | Сила штрафа за нелюбимый жанр              |
| alpha    | 0.6      | Баланс между средним и наименее довольными |
| beta     | 0.4      | Бонус за попадание в контекст «сегодня»    |
| rho      | 0.15     | Сила поправки за качество (рейтинг API)    |
| mu       | 0.7      | Баланс релевантности и разнообразия в MMR  |
| kappa | 0.5 | Вес "смягчённого вето" на контекстный жанр |
| M        | 50       | Размер пула кандидатов для MMR             |
| K        | 20       | Размер итоговой подборки                   |
